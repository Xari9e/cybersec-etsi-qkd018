# QKD Orchestration Interface for SDN

YANG models for [ETSI GS QKD 018 V1.1.1 (2022-04)](https://www.etsi.org/deliver/etsi_gs/QKD/001_099/018/01.01.01_60/gs_QKD018v010101p.pdf) "Quantum Key Distribution (QKD); Orchestration Interface for Software Defined Networks", which specifies orchestration interfaces between SDN controllers managing SDN-enabled QKD nodes and an SDN orchestrator, developed by [ETSI ISG QKD](https://www.etsi.org/committee/qkd).

Note: The default branch in this repository has been renamed `main` as per QKD(23)033d002.
